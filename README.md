# Landau Geometry of Computational Resources

**Conor Sheridan**

A differential geometry of computational resource bounds, starting from familiar Landau notation such as **O(n)** and **O(n²)**.

The manuscript represents asymptotic budgets as modules of admissible costs. It constructs a classifying locale for families of budgets, connects computational feasibility to topology, and develops differential and formal geometry from measured execution.

## Main results

- **A universal resource budget.** Parameter-dependent budget families are classified by maps into a resource locale and obtained by pulling back its universal budget.
- **Optimality as compactness.** Within the constructed framework, a problem's feasible open is supercompact if and only if an asymptotically optimal implementation exists. It is compact if and only if a finite asymptotically dominating portfolio exists.
- **Differentiation of measured computation.** Polynomial weights on execution events produce Taylor coefficients that agree with geometric jets. Varying the budget leads to tangent spaces and successive lifting obstructions.
- **Formal resource geometry.** The development includes formal completion, de Rham forms, connections, stratifications, and crystalline jets. A measured example has polynomial bounds at every finite order without one polynomial bound for the complete coefficient family.

The foundations use effective domain theory internal to **Hyland's effective topos**, with rational-valued cost functions and their eventual germs.
